# Implementing a Vue component

1. Confirm the component name, typed props, emitted events, and acceptance criteria.
2. Change product code under `src/` only.
3. Use `<script setup lang="ts">` and PascalCase component names.
4. Keep styles scoped unless the task explicitly requires global styles.
5. Run `npm run type-check` and `npm run build`.
6. Report files changed and verification evidence.
